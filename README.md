# Seniors 2026 — Thanaweya Cinematic Chronicle

A cinematic, interactive academic yearbook and celebration platform built for the Egyptian Thanawya Amma Seniors 2026 cohort.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Deployed on Cloudflare Pages](https://img.shields.io/badge/Deployed%20on-Cloudflare%20Pages-orange)](https://thanaweya-cinematic-chronicle.pages.dev)

## Live Demo

- **Live URL**: [https://thanaweya-cinematic-chronicle.pages.dev](https://thanaweya-cinematic-chronicle.pages.dev)

## Features

- **Cinematic Visual Storytelling**: Dark-mode aesthetic with fluid typography, confetti celebration triggers, and ambient lighting.
- **Interactive Photo Wall**: Embla Carousel and dynamic memory grid showcasing senior milestones and high school memories.
- **Student & Memory Directory**: Searchable directory of classmates, aspirations, and memorial quotes.
- **Zero-Downtime Edge Deployment**: Deployed natively to Cloudflare Pages for instant global edge delivery.

## Tech Stack

- **Framework**: React 19 + TanStack Start / Vite
- **Styling**: Tailwind CSS v4 + Radix UI Primitives
- **Animations**: Framer Motion
- **Hosting**: Cloudflare Pages / Workers
